# Andromeda Discord Bot – Privacy Policy

1. Data Collection and Processing
The Andromeda Bot collects and processes only the minimum amount of data required for its core functionality. This includes:
- Discord Server IDs, Channel IDs, and User IDs to manage bot features, configurations, and internal database records (via aiosqlite).
- Message content strictly limited to commands triggered by users (the Bot does not log, monitor, or store regular user conversations).

2. Use of Data
Collected data is used solely within the Bot to provide its standard features, such as tracking user statistics, levels, economy systems, or enforcing server moderation settings.

3. Third-Party Disclosure
We do not sell, trade, rent, or otherwise share any collected user or server data with third parties or external services. All data is securely stored within the hosting environment.

4. Data Retention and Deletion
Users have the right to request the complete removal of their stored data from the Bot's database. To request data deletion, please contact the developer via: [Miokesu / 1111790955088072810 or [Support Server Link](https://discord.gg/VYNSuVzDUR)]. If the Bot is removed (kicked) from a server, data related to that server may be permanently deleted within 30 days.
